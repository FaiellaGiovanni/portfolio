# Portfolio — a website built with C++

A personal portfolio generated by a static site generator written from scratch in C++17.
You write pages as Markdown text files; the C++ program turns them into a finished website.

```
portfolio/
├── content/            ← YOUR WORDS: edit these
│   ├── site.cfg        name, tagline, email, links
│   ├── index.md        intro text on the home page
│   ├── about.md        the About page
│   └── projects/       one .md file per project
├── templates/          HTML layouts with {{placeholders}}
├── static/             copied as-is: css/, images/, later sims/
├── generator/src/      the C++ site generator
│   ├── main.cpp        reads content, builds every page
│   ├── markdown.cpp    Markdown → HTML converter
│   ├── templates.cpp   fills {{placeholders}}
│   └── util.cpp        file + string helpers
├── sims/               (next step) C++ simulations for WebAssembly
├── build/              compiled generator ends up here
└── public/             THE FINISHED WEBSITE (generated, don't edit)
```

## One-time setup (Windows)

1. **Install a C++ compiler.** Check first: open a terminal in VS Code (`` Ctrl+` ``) and run `g++ --version`.
   If that fails, install MSYS2 from https://www.msys2.org, open the **MSYS2 UCRT64** terminal and run
   `pacman -S mingw-w64-ucrt-x86_64-gcc`, then add `C:\msys64\ucrt64\bin` to your Windows PATH and restart VS Code.
2. **Install the recommended extensions.** When you open the folder, VS Code offers *C/C++* and *Live Server*. Accept both.

## Everyday use

1. Edit files in `content/`.
2. Press **Ctrl+Shift+B**. This compiles the generator and rebuilds the site.
   (Or run `build.bat` from the terminal.)
3. Click **Go Live** in the bottom-right status bar to preview `public/` in your browser.

You only need to recompile when you change the C++ code, but the build task does both every time; it takes a second.

## Writing pages

Each project file starts with a small header (frontmatter), then Markdown:

```
---
title: Wind Tunnel Test Rig
summary: One sentence shown on the project card.
date: Spring 2026
status: Complete
tags: SolidWorks, LabVIEW, Aerodynamics
order: 1
---
## Overview
Normal text, **bold**, *italic*, `code`, [links](https://example.com) and lists.
```

- `order:` controls the order on the Projects page (lowest first). The first three appear on the home page.
- Add a new top-level page by creating `content/something.md`. Give it `nav_order: 3` to put it in the menu.
- Put images in `static/images/` and reference them from a project page as `../images/photo.jpg`.
- `PROJECT-TEMPLATE.md` (in the main folder) demonstrates every supported feature. Copy it into `content/projects/` to start a new project.
